# 맘브릿지 디자인 기준 — 크림 에디토리얼 v1

시안 원본: 같은 폴더의 `Main.html`(홈), `List.html`(미션 목록), `Detail.html`(미션 상세).
브라우저로 열면 그대로 보인다(390px 모바일 기준). 이 문서와 시안이 다르면 시안이 기준이다.

## 1. 디자인 토큰

강조색은 `clay` 하나만 쓴다. 파랑·빨강·초록 같은 기본 Tailwind 색과 이모지 아이콘은 이번에 모두 걷어낸다.

### 글꼴 (`next/font/google`, `display: 'swap'`)

| 역할 | 글꼴 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| `font-serif` | Gowun Batang | 400, 700 | 화면 제목(h1), 섹션 제목(h2), 가게 이름(상세), 로고 |
| `font-sans` | Noto Sans KR | 400, 500, 700 | 본문, 버튼, 카드, 숫자 |
| `font-accent` | Cormorant Garamond Italic | 500 | 섹션 위 영문 머리말 한 줄(예: *After drop-off*) |

크기 단계: 30(홈 히어로) · 26(상세 제목) · 24(화면 제목) · 20(섹션 제목) · 18(상세 섹션 제목) · 15 · 14 · 13 · 12 · 11. 제목 `letter-spacing: -0.02~-0.03em`.

### 모양
- 모서리: 카드 사진 14~16px, 카드·상자 16~18px, 버튼·입력 12~14px, 칩·배지 999px, 작은 태그 6~8px
- 그림자 없음. 깊이는 `cream` 배경 위 `paper` 카드 + `line` 테두리로만 낸다
- 좌우 여백 20px, 섹션 간격 28~36px
- 터치 영역 최소 44×44px
- 아이콘: 1.5~1.8 굵기의 선 아이콘(시안의 인라인 SVG 또는 lucide-react). 이모지 금지

## 3. 화면별 기준

### 홈 `/`
1. 헤더 → 2. 동네 선택 칩(로그인 시 내 활동 지역, 비로그인 시 "지역 선택") → 3. 히어로 제목 3줄(serif 30) + 설명 + 검색창 → 4. 탭 → 5. "등원 후 다녀오기 좋은"(rail 카드, 가로 스크롤) → 6. "처음이라면, 선정이 쉬운 미션부터"(row 카드 상자) → 7. 다음 정산일 카드(ink 배경, 로그인한 참여자만) → 8. 사장님 안내 띠(로그인 안 했거나 고객사일 때) → 9. 푸터(사업자 정보는 `lib/legal.ts`의 `BUSINESS_INFO`를 사용, #12 머지 전이면 상호·대표·이메일만)
- 기존 "역할 카드 3개(소상공인/참여자/운영자)"와 "운영 흐름 5단계"는 삭제
- 비로그인도 미션 카드를 볼 수 있어야 한다(현재 공개 API 범위 안에서)

### 미션 목록 `/missions` (참여자 홈의 "미션 탐색" 탭도 같은 화면·같은 컴포넌트를 쓴다)
- 칩 줄: 지역(선택됨) · 평일 낮 · 아이 동반 · 재택 / 그 아래 탭 / "우리 동네 미션 n개" + 정렬(마감 임박순·최신순·보상 높은순)
- 2열 그리드(`MissionCard grid`), 세로 간격 22px
- 마지막에 "우리 동네 미션을 다 봤어요. 이웃 동네 미션 보기" 상자(점선 테두리)
- 빈 목록: 같은 상자 문구로 이웃 동네 제안 + 지역 바꾸기 버튼

### 미션 상세 `/missions/[id]`
- 사진 340px(여러 장이면 넘김 + `1 / n`), 위에 뒤로·공유 원형 버튼
- 정보 블록(paper): 배지·태그 → 동네 → 가게 이름(serif 26) → 제공 내용 → 보상(22, clay) + "수수료 10% 공제 후 n원 지급" + 오른쪽 신청 현황
- 일정(`ScheduleTimeline`) → 신청 전 확인(`NoticeBox`) → 방문 안내(지도 자리 + 주소·체험 시간·휴무) → 미션 내용(아이콘 4칸) + `KeywordBox` → 성과 기록 안내(ink 상자) → `StickyCTA`
- 댓글은 미션 내용 아래로 유지하되 같은 카드 스타일로

### 참여자 내 활동 `/participant` (시안 `Participant.html`)
- 하단 탭바의 "내 활동". 맨 위 ink 카드: 다음 정산일에 받을 금액(serif 30) + "수수료·세금 공제 후 · 승인 n건" + 지원 중·진행 중·누적 보상 3칸
- 밑줄 탭: 진행 중 · 지원 현황 · 제출 내역 · 보상 내역 (기존 탭 기능을 옮긴다. "미션 탐색"은 하단 탭 "미션"으로, "커뮤니티"는 하단 탭 "커뮤니티"로 분리)
- 진행 중 카드: 썸네일 + 가게 + 후기 마감 D-day + 5단계 막대(선정·방문·후기 제출·검수·지급, 지난 단계 clay, 현재 단계 clay 연하게+굵은 글자) + 다음 할 일 버튼(clay)
- 검수 중 카드에는 "내 후기로 들어온 방문 n회 · 고유 방문자 n명"(기존 `reviewStats`)
- 보상 받을 계좌 카드(계좌번호는 끝 4자리만)

### 고객사 홈 `/client` (시안 `Client.html`)
- 헤더: 영문 머리말 + 가게 이름(serif)
- 성과 카드(paper): 이번 달 후기 유입 방문 수(serif 34) + 고유 방문자·후기 수 + 최근 7일 막대(오늘만 clay) + "성과 리포트 자세히 보기"
- "내 미션" 카드 목록: 제목 · 모집 기간·인원 · 상태 배지 · 4단계 막대(모집·선정·체험·후기·완료) · 숫자 3칸(신청 또는 선정 / 후기 / 방문)
- 하단 고정 "새 미션 등록" 버튼(clay). 미션 등록 폼·결과 리포트·내 정보 화면도 같은 토큰(입력창 paper + line, 라벨 13px muted, 섹션 제목 serif)으로 바꾼다
- 고객사는 휴대폰으로도 쓰므로 모바일 우선, 1024px 이상에서는 가운데 최대 720px

### 관리자 `/operator` (시안 `Operator.html`, 데스크톱 기준)
- 왼쪽 메뉴(paper, 232px): 로고 + 기존 메뉴 9개 그대로, 선택 항목 ink 배경, 대기 건수는 clay 숫자 배지. 아래에 참여자·고객사 화면 미리보기
- "오늘 처리할 일"(serif 28) + 숫자 카드 5개. 처리할 것이 있는 카드(검수 대기·정산 대기 등 0보다 큰 대기 항목)는 ink 배경으로 눈에 띄게
- 검수 대기 표(미션·참여자·제출일·대가 표시 확인·검수하기) / 미션 상태 막대 + 범례 / 정산 대기 요약 + "정산 처리로 이동"
- 나머지 관리 화면(미션 관리, 대행 등록, 지원서 승인, 검수, 정산, 회원, 유입 성과, 설정)은 같은 표·카드·버튼 스타일로 통일. 상태 배지 색: 진행·확인 필요 = clay 계열, 완료·확인됨 = sage 계열, 종료 = ink, 임시저장 = line
- 1024px 미만에서는 메뉴가 위로 올라가 가로 스크롤 탭이 된다

## 6. 완료 기준 (PR마다)
- 390px(아이폰)과 1280px에서 깨지지 않는다. 데스크톱은 `max-width: 1120px` 가운데 정렬, 목록 3~4열
- 글자 대비 4.5:1 이상, 터치 영역 44px 이상, 아이콘 버튼에 `aria-label`
- 이모지·파랑 기본색이 남아 있지 않다(`grep`으로 확인)
- 기존 기능(신청, 찜, 댓글, 필터, 성과 표시)이 그대로 동작하고 테스트·type-check 통과
- PR 설명에 모바일·데스크톱 스크린샷 첨부
