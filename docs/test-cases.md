## 1. 테스트 범위 및 전략

### 테스트 레이어 구조

```
┌─────────────────────────────────────────────┐
│           E2E 테스트 (Cypress / Playwright)  │  ← 사용자 시나리오 전체 흐름
├─────────────────────────────────────────────┤
│        통합 테스트 (API / DB 레이어)          │  ← 서비스 간 연동 검증
├─────────────────────────────────────────────┤
│          단위 테스트 (Jest / Pytest)          │  ← 핵심 비즈니스 로직
└─────────────────────────────────────────────┘
```

### 우선순위 매트릭스

| 기능 | 비즈니스 중요도 | 기술 복잡도 | 테스트 우선순위 |
|------|---------------|------------|----------------|
| 인증 콘텐츠 제출·검수 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | **P0** |
| 정산 및 보상 지급 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | **P0** |
| 미션 등록 | ⭐⭐⭐⭐ | ⭐⭐⭐ | **P0** |
| 미션 탐색·신청 | ⭐⭐⭐⭐ | ⭐⭐⭐ | **P0** |
| 회원가입·인증 | ⭐⭐⭐⭐ | ⭐⭐⭐ | **P0** |
| 운영자 대시보드 | ⭐⭐⭐ | ⭐⭐⭐ | **P1** |
